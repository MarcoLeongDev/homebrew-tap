# MarcoLeongDev Homebrew Tap

Homebrew tap for [SubBar](https://github.com/MarcoLeongDev/subbar) — a macOS
menu-bar app that tracks your OpenCode Go & Minimax usage.

## Install

```bash
brew tap MarcoLeongDev/tap
brew install --cask subbar
```

China (中国大陆) users: the binary is served via jsDelivr's global CDN, so the
install works out of the box. Prefer tapping via Gitee? See the SubBar README.
